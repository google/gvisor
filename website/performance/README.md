# Performance data

This directory holds the continuous benchmark summaries generated from BigQuery:
- `latest.json`: Daily updated 30-day rolling medians across `runc`, `systrap`, and `kvm`.

The legacy static May 2020 CSV files have been retired and replaced by dynamic JSON delivery.
Continuous benchmark data is generated by tests in
[`test/benchmarks/`](https://github.com/google/gvisor/tree/master/test/benchmarks)
and ingested from Buildkite CI.
